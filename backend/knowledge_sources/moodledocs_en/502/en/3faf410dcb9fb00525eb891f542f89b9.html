Ludilearn

What is Ludilearn?

Ludilearn is a course format for Moodle that allows you to integrate adaptive gamification into your learning paths. This plugin aims to enhance learner engagement and motivation by personalizing game elements according to their profile or the teacher's choices. Ludilearn is intended for all Moodle users: teachers, administrators, and learners.

Principle:

The plugin acts as an ''intelligent overlay'': it automatically leverages Moodle's native features (activity completion and grading system) to add game elements to your courses, without requiring complex configuration or changes to your content.

The teacher does not need to do anything extra: gamification automatically adapts to the course structure and existing activities, according to the learner's profile or the teacher's choices. Thus, Ludilearn fosters engagement, motivation, and success, while remaining simple to use and compatible with all Moodle activities.



Main features

The 6 game elements
  • Score: Dynamic point system with multipliers and completion bonuses.
  • Badge: Three-level rewards (Gold, Silver, Bronze) and bonus badges.
  • Progression: Visualization of progress as a journey.
  • Avatar: Visual customization with unlockable elements.
  • Timer: Adds a time dimension to quizzes with penalties (note: this game element only works with quizzes).
  • Ranking: Anonymous comparison of performance between learners.
The 3 visual universes
  • Schoolchild: School-oriented design, ideal for primary and middle school.
  • High school student: Universe designed for teenagers and young adults.
  • Professional: Sober theme for continuing education.
The 3 assignment modes
  • Automatic (adaptive): Personalized assignment according to the player profile (HEXAD questionnaire).
  • Manual: Choice of a single game element for the entire course.
  • By section: Customization of game elements for each course section.
Moodle compatibility

Ludilearn works with all Moodle activities and resources (mod). It uses the grading system and completion tracking. The plugin is regularly tested and compatible with the Boost and Pimenko themes.

Configuring the Ludilearn course format

Activating Ludilearn in a course

Go to your course settings. In the "Course format" section, select Ludilearn.

Choosing the game element assignment mode

Select the desired mode: Automatic, Manual, or By section.

In automatic mode, learners complete the HEXAD12 typology questionnaire upon their first login.

In manual mode, the teacher chooses the game element to apply in the course settings.

In by section mode, the teacher sets the game elements to use for each section:

  • Go to the course homepage
  • In the secondary menu, click "More" then "Ludilearn game elements customization"
  • On the new page, click the menu and select "Assign game elements by section".
  • For each section, choose the desired game element

Selecting the visual universe

In the course format settings, choose the universe suited to your audience (Schoolchild, High school student, Professional).

Disabling gamification on certain activities/sections

While editing the course, you can disable gamification on an activity or resource. This way, even if it has activity completion or a grade, the activity will not be gamified.

  • Enable editing mode on the course homepage
  • Find your activity and click the "action" menu
  • Use the "Do not gamify" option to exclude the resource or activity from gamification

Use for teachers

Creating and managing a gamified course: Add your resources and activities as usual. Ludilearn automatically adapts to the course structure. If you want to go further in customizing course gamification, many additional options are available from the "Ludilearn game elements customization" page.

Game element settings: Adjust multipliers, badge thresholds, completion bonuses, etc., according to your pedagogical objectives.

Tracking progress and game element assignments in automatic mode: Access the Ludilearn report to view assigned game elements, learner progress, and last access.

Pedagogical tips

  • Prefer automatic mode to use adaptive gamification.
  • Use manual mode to quickly apply gamification identically to the entire course.
  • Use by section mode to vary mechanics by topic and keep control as a teacher.
  • Don't hesitate to test the display with a student account to validate the user experience.

Learner experience

Navigation: Learners benefit from an enhanced interface, with a gamified navigation menu and visible progress indicators at all times.

HEXAD questionnaire: In adaptive mode, each learner answers 12 questions to determine their player profile. The algorithm then assigns the most motivating game element based on research results.

Visualization: Students see their score, progression, badges, avatar, timer, or ranking depending on the chosen mode. Rankings are anonymous and respect confidentiality.
