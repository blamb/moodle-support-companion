Using multiple markers

From MoodleDocs
Jump to:navigation, search
Main page ► Managing a Moodle course ► Activities ► Assignment ► Using multiple markers

  • Using Assignment
  • Assignment FAQ

When marking workflow, marking allocation, and multiple markers are enabled, different markers can be assigned to different students' submissions, with each marker grading independently.

Note: Only Simple grading is supported with multiple markers. When Rubrics or Marking guides used, you cannot assign a marker to the submission.

Key concepts

When multiple markers are in use, a distinction is made between a mark and a grade:

  • A mark is the provisional grade submitted by an individual marker for a submission.
  • A grade is the final value recorded in the gradebook, calculated automatically from the markers' marks once all markers have completed marking, according to the Calculate grade setting.

Allocating markers to students

Markers must be allocated to students before they can begin marking. There are two ways to do this.

Allocating individually

  1. From the assignment, click Submissions.
  2. Locate the student and click the three dots icon next to their submission.
  3. Select Allocate marker and choose a marker from the list.

Bulk allocating markers

  1. From the assignment, click Submissions.
  2. Select the students you want to allocate using the checkboxes.
  3. From the With selected menu at the bottom of the page, choose Set allocated marker.
  4. In the Set allocated marker for X selected user(s) form, assign a marker to each Allocated marker slot and click Save changes.

Marking a submission

All markers can see all submissions and each other's marks. To go directly to the submissions assigned to you, click the Mark allocated submissions button.

  1. Open the submission to grade.
  2. Enter a mark in the grade field.
  3. Set your marker workflow state (Not marked, Marking in progress, or Marking complete).
  4. Save changes.

The grading table shows a column for each marker (Marker 1, Marker 2, etc.) alongside the overall Status column. The overall workflow status updates automatically as markers progress.

Releasing the final grade

Once all markers have set their workflow state to Marking complete, the grade is calculated automatically according to the Calculate grade setting. If Manual is selected, the teacher in charge must enter the final grade themselves.

To release the grade to the student, set the submission workflow status to Released.

Site administration

A site-wide default number of markers can be configured in Site administration > Plugins > Activity modules > Assignment > Assignment settings. Educators can override this default when setting up individual assignments.
