It is the responsibility of each plugin developer to ensure that their plugin is compatible with the Moodle Mobile App.

Compatibility is not automatic: plugins that work correctly in the standard Moodle web interface may not function properly, or at all, within the app unless they have been specifically adapted for it.

Developers should follow the official Plugins development guide for the Moodle App to understand the requirements, available APIs, and best practices for building mobile-compatible plugins.

The following is a list of plugins reported by their developers as compatible with the mobile app.

Interactive Content – H5P

Component: mod_hvp

URL: https://moodle.org/plugins/mod_hvp

Description: Create and add rich content inside your LMS for free. Some examples of what you get with H5P are Interactive Video, Quizzes, Collage and Timeline.

Custom certificate

Component: mod_customcert

URL: https://moodle.org/plugins/mod_customcert

Description: Enables the creation of dynamically generated certificates with complete customisation via the web browser.

Attendance

Component: mod_attendance

URL: https://moodle.org/plugins/mod_attendance

Description: A plugin that allows an attendance log to be kept. - includes an optional block for easy access to relevant functions.

BigBlueButton BN

Component: mod_bigbluebuttonbn

URL: https://moodle.org/plugins/mod_bigbluebuttonbn

Description: Integrate BigBlueButton within Moodle - including record and playback of sessions.

Zoom meeting

Component: mod_zoom

URL: https://moodle.org/plugins/mod_zoom

Description: Zoom is a video and web conferencing platform that gives authorized users the ability to host online meetings and webinars.

Questionnaire

Component: mod_questionnaire

URL: https://moodle.org/plugins/mod_questionnaire

Description: Custom Survey Creation

Checklist

Component: mod_checklist

URL: https://moodle.org/plugins/mod_checklist

Description: A checklist can be created by a teacher (or generated from the activities in a course) and then the students or teachers can check-off each item as they are completed.

Subcourse

Component: mod_subcourse

URL: https://moodle.org/plugins/mod_subcourse

Description: Subcourse behaves as a graded activity. The grade for each student is automatically fetched from a final grade in another course. This allows course designers to organize the learning content into separate units.

Certificate

Component: mod_certificate

URL: https://moodle.org/plugins/mod_certificate

Description: This module allows for the dynamic generation of certificates based on predefined conditions set by the teacher. NOTE: This plugin is no longer receiving any new features. Only bug fixes are being applied. I have been working on a new plugin which can be located at https://moodle.org/plugins/mod_customcert which allows complete customisation of the PDF via the browser, whereas this plugin requires FTP and PHP knowledge. Both plugins can be installed on a site at once with no issues.

Group choice

Component: mod_choicegroup

URL: https://moodle.org/plugins/mod_choicegroup

Description: This module allows students to enrol themselves in a group within a course. The teacher can select which groups students can chose from and the maximum number of students allowed in each group.

Jitsi

Component: mod_jitsi

URL: https://moodle.org/plugins/mod_jitsi

Description: This module allows creating jitsi-meet videoconference sessions.

Gapfill

Component: qtype_gapfill

URL: https://moodle.org/plugins/qtype_gapfill

Description: Cloze (fill in the blanks) question type with VERY simple question creation syntax. Can do drag drop, dropdowns or gapfill questions

Video Time

Component: mod_videotime

URL: https://moodle.org/plugins/mod_videotime

Description: Embed videos from Vimeo and Youtube easily in your course, use activity completion to track videos and much more!

Treasure Hunt

Component: mod_treasurehunt

URL: https://moodle.org/plugins/mod_treasurehunt

Description: Outdoor, indoor and virtual-map treasure-chases with geolocation and QR codes. This module for Moodle allows to organize outdoor-serious-games with your students. TreasureHunt supports Moodle Mobile App and also implements a browser-based play application (no need to install any native app) and a geographical editor for encoding the stages of the game. The game can be configured with a range of options that make the module to be very flexible and useful in many situations: individual/team, moving/desktop-marking, scoring from time, position, completion, etc.

Mail

Component: local_mail

URL: https://moodle.org/plugins/local_mail

Description: Webmail-like messaging

Google Meet™ for Moodle

Component: mod_googlemeet

URL: https://moodle.org/plugins/mod_googlemeet

Description: The Google Meet™ for Moodle plugin allows the teacher, without having to leave Moodle, to create a Google Meet room and make available to the students the recordings of the room saved in Google Drive.

Formulas question type

Component: qtype_formulas

URL: https://moodle.org/plugins/qtype_formulas

Description: This is a question type plugin for Moodle with random values and multiple answer fields.

Word Select

Component: qtype_wordselect

URL: https://moodle.org/plugins/qtype_wordselect

Description: A very easy to use "select the words" Moodle question type.

All-or-Nothing Multiple Choice

Component: qtype_multichoiceset

URL: https://moodle.org/plugins/qtype_multichoiceset

Description: The all-or-nothing multiple choice question is a version of the core multi-answer multiple choice question with modified grading. In an all-or-nothing multiple choice question, a respondent can choose one or more answers. If the chosen answers correspond exactly to the correct choices defined in the question, the respondent gets 100%. If he/she chooses any incorrect choices or does not select all of the correct choices, the grade is 0%.

Signup Sheets

Component: mod_tutorialbooking

URL: https://moodle.org/plugins/mod_tutorialbooking

Description: The signup sheets module (formerly known as tutorial booking) is designed to allow instructors of a course to create slots that the students can sign themselves up to.

Regular expression short answer

Component: qtype_regexp

URL: https://moodle.org/plugins/qtype_regexp

Description: This question type (for the Moodle quiz module) aims at a more advanced system of student's response analysis, through the use of regular expresssions. This question type is an extension of the SHORTANSWER type. It can be used on its own and can also be incorporated into the existing Cloze (embedded) question type.

Kprime(ETH)

Component: qtype_kprime

URL: https://moodle.org/plugins/qtype_kprime

Description: A four option multiple true-false question type for moodle, as introduced by Krebs (1997). Kprime questions consist of an item stem and four corresponding statements or options.

Wordcloud

Component: mod_wordcloud

URL: https://moodle.org/plugins/mod_wordcloud

Description: With the wordcloud activity, it is possible to collect terms together with your course participants in a brainstorming process and to display them graphically in order of frequency. This can be used, for example, to capture a picture of the mood or to create a basis for a discussion.

MTF (ETH)

Component: qtype_mtf

URL: https://moodle.org/plugins/qtype_mtf

Description: Multi True false in one stem (question). Brief: The MC question type as it exists in Moodle is not very ideal, since you can only configure questions which are not very well designed regarding best practices of MC questions. Teachers can have more than one true/false question in same stem. this saves creating new questions for each stem. especially when it comes to an essay followed by many questions.

ReadSpeaker for Moodle

Component: block_readspeaker_embhl

URL: https://moodle.org/plugins/block_readspeaker_embhl

Description: Use this Moodle block to quickly and easily integrate text-to-speech tools for accessibility, inclusion and engagement into your Moodle instance. Visit www.readspeaker.com/moodle for more information.

MEDIAL Video Streaming Activity

Component: mod_helixmedia

URL: https://moodle.org/plugins/mod_helixmedia

Description: This Moodle video plugin allows Teachers / Lecturers to upload video or audio files using a specific MEDIAL Activity, creating a link to the file on the course page.

Deft response

Component: block_deft

URL: https://moodle.org/plugins/block_deft

Description: Real time communication with Texts, Choices, Comments, and conference Venues. It is a much better way to use a poll, chat, and audio/video conference in Moodle.

Plenary meeting Activity

Component: mod_plenum

URL: https://moodle.org/plugins/mod_plenum

Description: The Plenary meeting activity facilitates parliamentary meetings in person or with audio and video conferencing. Actions are recorded by the activity to help provide minutes to be used to assess participation.

CADO: Course outline & approval

Component: mod_cado

URL: https://moodle.org/plugins/mod_cado

Description: Generates an interactive curriculum report from Moodle-held course information. Provides a course approval workflow within Moodle. Allows course variants to be compared, with differences highlighted. Upon approval, displays to students in either browser or Moodle app.

ForumNG

Component: mod_forumng

URL: https://moodle.org/plugins/mod_forumng

Description: Alternative forum with AJAX and management features

Single choice (ETH)

Component: qtype_sc

URL: https://moodle.org/plugins/qtype_sc

Description: Teachers can have more than one (single) true/false question in same stem. this saves creating new questions for each stem. especially when it comes to an essay followed by many questions.

VideoFront Vídeo

Component: mod_videofront

URL: https://moodle.org/plugins/mod_videofront

Description: Plugin for video library integration with Moodle

Alphabees AI Tutor / AI Chat

Component: block_alphabees

URL: https://moodle.org/plugins/block_alphabees

Description: The Alphabees Moodle Plugin integrates a powerful AI tutor chat widget into Moodle, enabling precise placement using Moodle's block structure. It seamlessly combines integration with a high-quality custom UI and backend, fully customizable through the Alphabees portal. This plugin leverages Moodle's flexible block placement capabilities while incorporating robust WebSocket-driven communication and advanced customization options, ensuring a high-performance and user-friendly AI tutoring solution.

Quickom

Component: mod_quickom

URL: https://moodle.org/plugins/mod_quickom

Description: QUICKOM - the leading technology platform for live-class teaching and lecture hall-based conferences.

STREAM All-in-One Video Platform Activity

Component: mod_stream

URL: https://moodle.org/plugins/mod_stream

Description: Stream is a cutting-edge video platform designed for schools, seamlessly integrating with current systems for optimal teaching. This Moodle plugin brings Stream's advanced features into your LMS, enriching the learning journey for both teachers and students.
